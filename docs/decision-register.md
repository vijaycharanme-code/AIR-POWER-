# Versioned implementation decisions

1. **Scope:** Gate A is implemented. Numeric RUL and simulation remain blocked stubs as required by the source. No aircraft, maintenance-release, flight, or work-order write-back exists.
2. **Gemini exception:** The user's current instruction permits an optional cloud API despite the brief's no-cloud-inference default. It supplies explanations on explicit request only and cannot call the DecisionGate or change a case. The UI discloses that selected evidence leaves the computer. Model is configurable; default `gemini-flash-latest`. No key is included.
3. **Schemas:** Four domain contracts are version 1.0. Unknown units, nonfinite values, naive timestamps and invalid schemas are quarantined. A malformed top-level request is rejected with HTTP 422. Original quarantined source records remain in the database.
4. **Clock:** Built-in fixture timestamps are shifted together from the frozen anchor to import time, preserving relative staleness and epoch defects. Uploaded bundles retain their actual timestamps. UTC is used for comparisons; the original offset is retained in source snapshots. Current means event <= ingest <= decision time, age <= policy max_age_hours.
5. **Policy:** Per-case policy requires explicit RUL applicability. Default fixture maximum age is 24 hours. No RUL numerical estimate is accepted in Gate A.
6. **Window:** A demo window is feasible only when serviceable parts can arrive before its end and the agency has capability, capacity, and approval. This is an advisory prerequisite check, not a scheduler or a maintenance-duration model.
7. **Rank:** Ascending lexicographic validity, feasibility (feasible/unknown/hard), descending urgency, descending consequence, ascending warning lead hours, quality, case ID. Unknown factors sort last. Version `gate-a-v1`; this is a demo policy, not operational doctrine. Ranking never implies approval.
8. **Version semantics:** Imports that change evidence, evaluations, and dispositions append a new case version and event atomically. Same request/key replays the original response even when its If-Match is now old. The same key with changed input/version returns 409. Changed evidence clears the current evaluation; historical results remain available. A recorded gate is a historical result at decision_time; freshness can change afterward. Re-evaluate before relying on a newly stale case.
9. **Local identity:** Startup principal and role are configuration, not user authentication. Bound to loopback. No role-switch endpoint. API callers without Origin are allowed for local CLI use; browser cross-origin mutations are denied. Do not expose on a public interface.
10. **Concurrency:** One instance serializes transactional writes with a process lock. SQLite foreign keys and unique constraints guard persistence. Frozen suite executes synchronously and is bounded to 280 cases; there are no queues or workers. This is intentionally not a multi-worker deployment.
11. **Artifacts:** UUID logical IDs, private fixed root, temp-write then atomic rename, DB registry SHA-256, verification on read. A rollback after file creation can leave an unregistered orphan; it is never downloadable. History and hashes are not tamper-proof against an owner of the host.
12. **Evaluation limits:** Frozen holdout has 120 valid plus six invalid fault families of 20. These tests verify policy mechanics on generated fixtures, not field prediction accuracy. Development has 40 cases. Stateful paths are separate pytest tests. The API's frozen-suite report does not pretend to run pytest or browser tests.
13. **Requirement source:** Only this supplied consolidated brief is available, not the earlier 47-file research package or complete RTM. Traceability covers named F01–F09/F12/F13 and explicitly cited FR/NFR IDs; no claim is made to reconstruct unseen requirements.
14. **Platform:** Python 3.12, SQLite, one FastAPI process, React 18 + Vite SPA. Prebuilt assets are bundled so Node is needed only to modify or test frontend source. Initial Python install requires internet; Gemini also requires internet. Windows launcher is provided; automated validation was executed on Linux, not Windows.
